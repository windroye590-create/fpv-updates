# FPV Комісія 1.0.2 / 3

Виправлено втрату зв’язку з локальним модулем і видалення курсантів зі старими результатами без ID.

- Локальний модуль продовжує працювати, коли Windows призупиняє фонове вікно. Збереження та видалення залишаються доступними після тривалого простою.
- Перед видаленням курсанта можна переглянути неоднозначні старі рядки таблиці та для кожного вибрати: видалити разом із цим акаунтом або залишити.
- Зміна рядків після перегляду потребує нового підтвердження. Записи з ID іншого курсанта зберігаються.
- Після видалення останнього курсанта можна видалити порожню групу, якщо вона більше не призначена тестам.

Збережено власну іконку FPV, окремі локальні дані, Google-таблиці та ключ підпису автооновлень. Сервер оновлюється перед публікацією EXE.

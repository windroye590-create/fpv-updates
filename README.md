# FPV Комісія для Windows

Окремий застосунок на основі Літакової Комісії 1.2.34, зі збереженням усіх
функцій: тести, письмові роботи, матеріали, групи, курсанти, перевірка робіт,
банк питань, Excel, архіви, захищені локальні дані та автооновлення.

Назва: **FPV Комісія**. Підпис розробника й першого інструктора: **Розробник**.
Власник Google: `fpv.training.center@gmail.com`.

## Готовий випуск

**[Завантажити FPV Комісію 1.0.0 для Windows](https://github.com/windroye590-create/fpv-updates/releases/download/v1.0.0/FPV-Komisiia-PC.exe)**.
Google підключений, таблиці готові, окремий канал підписаних автооновлень працює.
Опубліковані файли завантажено й звірено з підписаним каталогом; перевірка
готового EXE на Windows пройшла 16 сценаріїв. [Звіт перевірки](release-staging/v1.0.0/published-verification.json).

Для першого входу відкрийте реєстрацію інструктора: ім’я `Розробник`, логін
`WindRoy`, власний новий пароль і приватний код із локального скрипту
налаштування. Код і пароль не потрібно нікому надсилати.

## Початкове підключення

Перший стабільний EXE публікується після налаштування власника та перевірки
Google. Поточний код перевіряється на ізольованих даних без звернень до
бази Літакової Комісії.

1. Власник запускає [одноразовий скрипт налаштування](release-tools/setup-automation.ps1)
   у Windows PowerShell. Git, winget та права адміністратора не потрібні.
2. Скрипт відкриває GitHub і Google у браузері, перевіряє саме FPV-акаунт,
   створює окремий RSA-3072 ключ і записує облікові дані в Actions Secrets.
   Паролі, токени й приватний ключ не потрапляють у код або журнал GitHub.
3. [Процес підключення](https://github.com/windroye590-create/fpv-updates/actions/workflows/bootstrap-fpv.yml)
   створює окремі таблицю, Apps Script і розгортання. Після підготовки він
   показує посилання на Google-редактор.
4. Під `fpv.training.center@gmail.com` відкрийте цей редактор, виберіть функцію
   `setupCommission` та один раз натисніть «Виконати». Google попросить
   надати новому проєкту доступ до таблиць. Успішне виконання завершує авторизацію.
5. Запустіть [стабільний випуск](https://github.com/windroye590-create/fpv-updates/actions/workflows/release.yml)
   з версією `1.0.0`. Сервер і підпис перевіряються перед публікацією EXE.

Для реєстрації першого інструктора використайте логін `WindRoy`, ім’я
`Розробник` і приватний код, показаний локальним скриптом налаштування.
Пароль облікового запису обирається у застосунку. Код діє 24 години й перестає
працювати після реєстрації першого інструктора. Якщо він прострочений,
власник може створити новий через `createInitialInstructorCode` у своєму Google-проєкті.

Приватний ключ зберігається на ПК власника в
`%LOCALAPPDATA%\FPVReleaseTools\signing\fpv-release.p12` з обраним ним паролем.
Локальна копія пароля захищена Windows DPAPI. Збережіть окрему приватну
резервну копію P12 та пароль: вони потрібні для відновлення на іншому ПК.

## Незалежність комісій

- EXE: `FPV-Komisiia-PC.exe`.
- Папка локальних даних: `%LOCALAPPDATA%\FPVKomisiiaPC`.
- Окремі Google-ресурси, ключ підпису й репозиторій оновлень.
- Версії та випуски FPV незалежні від Літакової Комісії.
- [Походження спільного коду](upstream-source.json) фіксує початковий коміт.
  Спільні виправлення переносяться окремим переглянутим оновленням із тестами;
  спеціальні зміни FPV зберігаються у цьому репозиторії.

## Перевірки

`npm --prefix source test` перевіряє логіку. `npm --prefix source run test:ui`
перевіряє справжній інтерфейс у Chromium на синтетичних даних.
`python3 -m unittest discover -s release-tools/tests` перевіряє розгортання,
ізоляцію власника, відновлення після збоїв і збереження ключа підпису.
До підключення Google лише ізольована CI-перевірка може збирати EXE з
`COMMISSION_ALLOW_UNCONFIGURED_TEST=1`; стабільний випуск цього дозволу не має.

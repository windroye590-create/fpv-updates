# FPV Комісія для Windows

Версія й код поточного випуску наведені в [package.json](package.json).

Розробник.

Розділ «Матеріали» тимчасово вимкнено. Файли та історія збережені; PDF-відомості й Excel доступні.

Кнопка «Оновити дані» об’єднує збереження, синхронізацію та оновлення розділу.
Повторні натискання приєднуються до поточного циклу.
Стабільний випуск доступний через автооновлення GitHub.
Повний перелік — у [примітках випуску](release-notes.md).

`npm test` включає регресії для відтворених помилок. `npm run test:ui`
перевіряє інтерфейс, а `npm run test:packaged` — ресурси готового EXE.
Для незалежної перевірки книг Excel потрібен `openpyxl==3.1.5` у Python.

Сервер Apps Script має окреме розгортання. Номер сумісного API залишається 26,
ідентифікатор серверного випуску визначає автоматизація перед розгортанням.

Якщо видаленню акаунта заважають старі рядки результатів без ID, вікно підтвердження показує їх перед видаленням. Для кожного рядка оберіть, чи належить він цьому курсанту. Рядки, обрані для збереження, залишаться в таблиці.

Оптимізація рейтингу використовує кеш максимум трьох груп на акаунт поза збереженим станом. Заміна масивів результатів, тестів чи курсантів, нові ревізії кабінету або `resultWriteVersion` скидають його; пошук і експорт читають однаковий актуальний рейтинг.

Новий клієнт запитує `reviewQueueProtocol: 2` та `includeRecoveries: true`. За незмінної ревізії сервер повертає лише актуальну присутність інструкторів; повне перечитування виконується щонайменше раз на п’ять хвилин і завжди при ручному оновленні. Старі сервери й клієнти підтримують попередні окремі запити. Перевірка сесії виконується при кожному запиті.

`node tests/optimization.mjs` перевіряє інвалідацію кешу, відмови диска, об’єднання збережень і сумісність протоколу. `node tests/optimization-ui.mjs` запускає реальний Chromium на 12 000 синтетичних результатів; `LITAKOVA_OPT_WEB_ROOT` і `LITAKOVA_OPT_BASELINE=1` дозволяють порівняти старий код. `node tests/optimization-server-volume.mjs` вимірює читання локальної моделі Sheets; це не навантажувальний тест робочого Google-сервера.
